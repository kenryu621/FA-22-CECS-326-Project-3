# Project 3 - All About Deadlock

Organization: California State University

Semester: Fall 2022

Course: CECS 326 - Operating System

Project description: The third project is about implementing the synchronization tool to prevent a deadlock situation in an imagined scenario where a road between the east and the west village can only have one driver on the road at a time.

Author: Diego Garcia and Kenry Yu

## Instructions

1. To compile and run the program, first ensure you have Java Development Kit (JDK) installed in your operating system.
2. Open the terminal.
3. Git clone the repository `git clone https://github.com/kenryu621/FA-22-CECS-326-Project-3.git`
4. Change your directory to the folder containing the source files using the `cd` command.
    - For example: `cd FA-22-CECS-326-Project-3/`
5. Compile the source files by running `javac project3/*.java` in the terminal. This will compile all of the Java files in the "project2" folder.
6. You should now be able to see `.class` files in the "project3" folder compiled by the JDK.
7. Run the program by running `java project3.RoadController` in the terminal and observe the outputs.
8. To stop the program, simply press Ctrl + C (or Command + C) in the terminal to cancel it.

## Results

The program should continue to run until the user cancel the operation. The program is designed to avoid a deadlock on the road between the east and west village.
